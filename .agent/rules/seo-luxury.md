# Estándares Técnicos Azimut Property (Luxury Framework)

1. **Semántica:** Cada página debe tener un único H1 descriptivo con keyword + ubicación.
2. **Rendimiento:** Mantener CLS < 0.1. Ningún script debe bloquear el renderizado visual.
3. **IA/GEO:** Obligatorio incluir Schema.org (RealEstateAgent, Product o Place) en todas las vistas.
4. **Vibe:** Estética minimalista, "Quiet Luxury". Evitar pop-ups intrusivos.
5. **Tono:** Analítico, sofisticado, basado en datos de mercado 2026 (sin "salesy" language).
